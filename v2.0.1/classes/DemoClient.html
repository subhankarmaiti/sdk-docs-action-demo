    Class DemoClient

    The entry point to the SDK.

    One client per set of credentials; it is safe to share across concurrent requests and holds no per-request state.

    Example

    const client = new DemoClient({
      apiKey: process.env.DEMO_API_KEY!,
      retry: { maxAttempts: 4 },
    });
