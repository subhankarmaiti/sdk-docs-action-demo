      SDK Docs Action Demo

      A small demonstration SDK for sdk-docs-hub.

      It exists so the documentation action has something realistic to publish: enough surface area to produce a multi-page site with a sidebar and a search box, which is what the version selector has to mount itself into.

      Example: Creating a client and fetching a widget

      import { DemoClient } from 'sdk-docs-action-demo';

      const client = new DemoClient({ apiKey: process.env.DEMO_API_KEY! });
      const widget = await client.widgets.get('wgt_123');
      console.log(widget.name);
